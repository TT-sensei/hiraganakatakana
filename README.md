# かなカナ

ひらがなとカタカナを、書いて練習できる小学生向けの学習アプリです。

## できること

- ひらがな・カタカナの書き取り練習
- お手本をなぞる練習と、お手本なしの練習
- 1文字ずつ取り組める練習モード
- ひらがな・カタカナのテスト
- 10文字に挑戦するランダムテスト
- とっくん・にがて問題・ふくしゅうモード
- 毎日のデイリーミッション
- 学習状況、経験値、連続学習日数の記録
- 学習の進み具合に応じたレベルアップ
- 文字ごとの達成状況の確認
- Koboyo Iconsなどを使った文字のヒント表示

## 使い方

1. れんしゅうする文字を選びます。
2. 画面のお手本を見ながら、指やマウスで文字を書きます。
3. 3回の練習に取り組んだら、テストに挑戦します。
4. テストに合格した文字は、できるようになった文字として記録されます。
5. 「ランダムテスト」や「ふくしゅう」で、覚えた文字を確かめます。

練習をしていない文字でも、最初からテストに挑戦できます。

## 対象

- 小学校低学年
- ひらがな・カタカナの学習を始める子ども
- タブレットやパソコンで文字を書く練習をしたい子ども

## 記録について

学習記録は、使用している端末のブラウザに保存されます。アカウント登録やサーバーへの送信はありません。
